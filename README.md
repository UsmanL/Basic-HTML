# 🌐 Simple HTML Starter

A clean, lightweight, and beginner-friendly basic HTML project template. Perfect for quick mockups, learning web basics, or starting a new web page from scratch.

## 📂 What's Inside?
- `index.html` — The main structure of the web page using semantic HTML tags.
- `style.css` — Basic styling and clean layout rules.

## 🚀 How to Run Locally
1. Clone this repository or download the ZIP file.
2. Open the folder in your code editor (like VS Code).
3. Simply double-click `index.html` to open it in any web browser, or use the **Live Server** extension for instant reloading.

## 💡 Purpose
Built as a straightforward, hassle-free starting point for web development experiments and static pages.
